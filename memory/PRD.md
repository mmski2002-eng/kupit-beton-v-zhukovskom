# ПСК «Прогресс» — сайт «купить бетон в Жуковском»

## Что это
Статический сайт на Next.js 16 (App Router, TypeScript, CSS Modules, `output: export`).
Продажа товарного бетона, растворов, услуг доставки/аренды. Данные — в `src/data`,
контент-страницы — markdown в `src/content/pages` (читается через `src/lib/content-pages.ts`).

## Запуск в среде
- supervisor `frontend` запускает `yarn start` в `/app/frontend` (симлинк → `/app`).
- `package.json`: `start` переопределён на `next dev -p 3000 -H 0.0.0.0`; прод-старт — `start:prod`.
